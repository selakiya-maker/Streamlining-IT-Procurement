# Streamlining IT Procurement: Automating Standard Laptop Order with Flow Designer

## Project Overview

This project focuses on streamlining the IT procurement process by automating the ordering of a standard laptop using "ServiceNow Flow Designer".

The system allows employees to submit a standard laptop request through the "Service Catalog". Once the request is submitted, the workflow automatically handles approval, catalog task creation, task assignment, notifications, status updates, and request completion.

## Problem Statement

The standard laptop procurement process can involve several manual activities such as submitting requests, obtaining approval, creating procurement tasks, assigning tasks, updating request status, and communicating with employees.

Manual handling of these activities can result in delays, repeated work, and difficulty in tracking requests.

## Objective

The main objective of this project is to automate the standard laptop procurement process using **ServiceNow Flow Designer** and reduce manual effort involved in processing laptop requests.

## Proposed Solution
The proposed solution uses a ServiceNow Service Catalog item for standard laptop requests and Flow Designer to automate the complete workflow.

The automated process includes:
- Employee submits a standard laptop request.
- Request is sent for approval.
- Approved requests continue to procurement.
- A catalog task is automatically created.
- The task is assigned to the Hardware/Procurement team.
- Notifications are generated for relevant users.
- Request status is updated throughout the process.
- The request is completed after the procurement process.
